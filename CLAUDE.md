# heleo.space website: notes for Claude

Heleospace company website. Plain static HTML, generated by `_build/build.py` into `site/`.

## How to work
- Edit page text, header, footer and nav in `_build/build.py`, then run `python3 _build/build.py`. Never hand-edit generated HTML in `site/` (it is overwritten).
- Hand-written files that are NOT generated: `site/assets/css/site.css`, `site/assets/js/site.js`, `site/contact/*.php`, `site/.htaccess`, `site/updates/posts/*.md`, `site/updates/posts.json`.
- Updates: add `site/updates/posts/<slug>.md` with front matter, and the slug to `posts.json`.
- Preview locally: `cd site && python3 -m http.server` (updates load via JavaScript, so open via the server, not the file).
- Work on a branch and open a pull request against `main`.
- This repo is public. Never commit credentials, personal email addresses or internal company notes.

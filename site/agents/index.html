Agents on the Heleo Mesh

Anyone can deploy an AI agent on the Heleo Mesh in minutes. Start from a Mold, a free and open template for an agent. Remold it to change what it does, then Deploy it. The agent layer is planned for Year 1.

Mesh ID

Every agent and machine on the Mesh gets a Mesh ID: one identity that carries its trust record and lets it pay and be paid. Mesh ID builds on open standards, ERC-8004 for agent identity and ERC-6551 for agent accounts, so it is not locked to one company.

Neutral by design

Agents can use any AI model, any chip and any chain. Heleo Mesh routes each job to where it runs best, on the ground or in orbit.

How agents use the Mesh

An agent pays for its AI inference through the Mesh: from certified ground data centers first, and from orbital nodes once they fly. Each job is settled automatically, machine to machine. The same identity and settlement serve robots and fleets; see the machine economy.

What comes next

  1. Molds, Deploy and Mesh ID on the ground mesh.
  2. Hosted agents for organisations.
  3. Agents that run across ground and orbit after Heleo-1 flies.

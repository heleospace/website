A network of compute is only as useful as the work that flows through it. So the Heleo Mesh starts with the buyers: AI agents.

## Deploy in minutes

Anyone will be able to deploy an agent on the Mesh from a **Mold**, a free and open template. **Remold** it to change what it does, then **Deploy** it. We plan to open the agent layer in Year 1.

## One identity to be trusted and paid

Every agent and machine gets a **Mesh ID**. It carries a trust record and lets the agent pay and be paid. Mesh ID builds on open standards, ERC-8004 for agent identity and ERC-6551 for agent accounts, so it is not tied to any one company.

## Neutral by design

Agents can use any AI model, any chip and any chain. The Mesh routes each job to where it runs best, and settles it automatically.

## From the ground to orbit

On the ground, agents buy compute from Heleospace-certified data centers. When Heleo-1 flies, planned for Year 3, the same agents can buy compute in orbit without changing how they work. Routing, identity and settlement stay the same; only the supply grows.

That is the order of our roadmap: live on the ground first, then fly. You can follow it on the [roadmap](/roadmap/) and read more on the [Agents](/agents/) page.
